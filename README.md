# Build Your Opinion on Evidence

An evidence-driven research and engineering series by [Ahmed Hisham](https://github.com/ahmedhisham73).

We study technical claims, build experiments, publish the evidence, and explain how it changes our opinion. The aim is a regular series of focused experiments in AI and data science.

## Explore the research

| Repository | Focus |
| --- | --- |
| [Machine Learning & Data Science](https://github.com/build-your-opinion-on-evidence/machine-learning-and-data-science) | Classical machine learning, statistics, data analysis, feature engineering, and evaluation. |
| [Deep Learning & AI](https://github.com/build-your-opinion-on-evidence/deep-learning-and-ai) | Neural networks, representation learning, computer vision, NLP, and model training. |
| [Generative & Agentic AI](https://github.com/build-your-opinion-on-evidence/generative-and-agentic-ai) | Generative models, LLMs, retrieval, agent orchestration, memory, and tool use. |

Each subject repository contains multiple projects under `projects/`. Code, configurations, results, references, and project-specific documentation live with the project. This hub links to those sources.

## What every experiment should show

1. The question and the expectation before testing.
2. Sources and the precise scope of the implementation.
3. The experimental setup, baseline, and how to rerun it.
4. Measured results, failures, runtime, and cost when relevant.
5. Interpretation, limitations, and what would change the conclusion.

Paper-inspired prototypes, partial implementations, and reproduction attempts must be described accurately. Results apply to the tested setup.
